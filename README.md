# 수업도우미 (Classroom Helper) — 오프라인 빌드

인터넷·서버 없이 동작하는 수업도우미 전체 묶음입니다.
이 폴더 하나가 전부이며, 정적 파일만 들어 있습니다.

## 구성

```
index.html          허브 (도구 9개 목록)
timer/              타이머
pomodoro/           뽀모도로 타이머
stopwatch/          스톱워치
worldclock/         세계시간
paint/              그림판(판서)
noise/              소음측정기
picker/             발표자 선정
instruments/        피아노 연주
ladder/             사다리

fonts/              Pretendard 등 웹폰트 (로컬)
shared/             세계지도 SVG, 국기 66종, 아이콘, 앱 아이콘
manifest.webmanifest / sw.js   오프라인 캐시용
```

## 여는 방법

`file://` 로는 열리지 않습니다. 브라우저 보안 정책상 ES 모듈이 차단되기 때문입니다.
**이 폴더를 HTTP 루트로 서빙**해야 합니다.

- 테스트: `npx serve .` 또는 `python3 -m http.server 8000`
- AI보드 앱(Flutter): 앱 안에서 `127.0.0.1` 루프백으로 이 폴더를 서빙하고 웹뷰로 엽니다.
- 웹 배포: 이 폴더를 사이트 루트로 올리면 됩니다.

## 외부 의존성

없습니다. 확인 방법:

```
grep -rE "https?://" --include=*.js --include=*.css --include=*.html . | grep -v w3.org
```

CDN 폰트, 지도 타일, 국기 이미지, 아이콘 라이브러리를 전부 로컬 파일로 바꿨습니다.

## 오프라인 캐시

`sw.js` 가 139개 파일을 전부 미리 받아둡니다.
브라우저에서 한 번 열면 그 뒤로는 서버가 꺼져도 동작합니다.
파일을 수정한 뒤에는 `scripts/make-sw.mjs` 를 다시 돌려 `sw.js` 를 갱신해야 합니다.

## 이 저장소가 굴러가는 방식 — «원본은 안 건드리고 한 겹 덧붙이기»

앱 10개는 AI Studio 가 만듭니다. 우리는 그것을 **고치지 않습니다.**
받아다 빌드한 «결과물» 위에 필요한 것을 한 겹 덧붙입니다.

고침은 두 종류이고, 성질이 아주 다릅니다.

| | 어디에 | 앱을 다시 가져오면 |
|---|---|---|
| **① 원본에 넣는 것** | `scripts/patches/*.patch` | 살아남습니다 (빌드 전에 다시 붙습니다) |
| **② 결과물에 덧붙이는 것** | `scripts/apply-fixes.mjs` 가 관리 | **전부 없어집니다** |

②가 없어져도 화면은 멀쩡히 열립니다. 그래서 아무도 모릅니다.
실제로 타이머 화면 하나에서 일곱 개가 조용히 사라지는 것을 확인했습니다.

그래서 두 가지를 만들어 두었습니다.

```
node scripts/apply-fixes.mjs     ② 를 한 번에 다시 입힙니다 (여러 번 돌려도 결과 같음)
node scripts/check-fixes.mjs     ② 가 다 붙어 있는지 대조합니다 (빠지면 실패)
```

`0. 앱 다시 가져오기` 는 마지막에 이 둘을 자동으로 돌리고,
하나라도 빠지면 «올리면 안 됩니다» 라고 멈춥니다.
`bash test/run.sh` 도 0번 검사로 같은 것을 봅니다.

도구를 새로 **추가**했다면 기준을 한 번 다시 적어 주세요.
반드시 «지금 상태가 맞다» 고 확인한 뒤에 하셔야 합니다.

```
node scripts/check-fixes.mjs --기준
```

퀴즈 앱을 AI Studio 에서 새로 받아 온 경우에도 같은 일이 생깁니다.
그때는 `node scripts/apply-fixes.mjs` 를 손으로 한 번 돌리면 됩니다
(퀴즈 쪽 고침까지 같이 다시 붙습니다). 다만 **문항 «내용»을 고치는
스크립트**(`quiz/scripts/fix-blanks.mjs` 등)는 자동으로 돌리지 않습니다.
자료 자체를 바꾸는 것이라 언제 돌려야 하는지가 다르기 때문입니다.
