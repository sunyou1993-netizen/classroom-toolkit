## 이제 세 군데가 다 같습니다

| | 상태 |
|---|---|
| 보드에 나가는 화면 (`quiz/*/assets/*.js`) | ✅ 759문항 |
| 소스 저장소 (`claix_quiz_*`) | ✅ 759문항 |

전에는 AI Studio 만 검증 전 문항이었습니다. 그래서 거기서 앱을 한 번만
손대면 커터칼날 배출 같은 지침과 반대인 문항까지 되살아났습니다.
이제 그 위험이 없습니다.

## 어떻게 했나 (다음에 또 할 때)

AI Studio 는 GitHub 로 **올리기(Push)만** 되고 **받아오기(Pull)가 없습니다.**
Export 메뉴에 있는 것은 이 셋뿐입니다.

```
Export to Antigravity  /  Push to GitHub  /  Download as .zip
```

그래서 코드 편집기에서 직접 바꿔야 하는데, 2만 자짜리 배열을
복사·붙여넣기로 옮기는 건 계속 실패했습니다(편집기가 iframe 안이라
클립보드가 안 건너갑니다). 그래서 이렇게 했습니다.

1. 배열 본문을 `quiz/scripts/questions/aistudio/*.txt` 로 깃허브에 올림
   (raw.githubusercontent.com 은 다른 사이트에서 읽는 것을 허용합니다)
2. AI Studio 편집기가 그 주소에서 **직접 받아서** 배열 자리에 넣음
3. ⌘S 로 저장 → 왼쪽에 «Checkpoint» 가 뜨면 끝

손으로 옮기는 단계가 없으므로 한 글자도 안 틀립니다.

**사람 손이 필요한 곳은 딱 하나** — 앱이 잠들어 있으면 화면 가운데 뜨는
**Launch** 버튼입니다. 이건 사람이 직접 눌러야만 동작합니다
(좌표 클릭·엔터·자바스크립트 `.click()`·이벤트 직접 발생 전부 안 먹힙니다).
Launch 를 안 하면 코드 편집기가 «Loading code...» 에서 멈춥니다.

| 앱 | 파일 | 바꿀 자리 | 넣을 내용 |
|---|---|---|---|
| 환경보호 | `js/main.js` | `questions: [ … ]` | `aistudio/arr_env.txt` |
| 안전 | `js/main.js` | `questions: [ … ]` | `aistudio/arr_safe.txt` |
| 학교폭력 | `js/main.js` | `questions: [ … ]` | `aistudio/arr_vio.txt` |
| 속담맞추기 | `js/proverbs_data.js` | `RAW_PROVERB_DATA = [ … ]` | `aistudio/arr_pv.txt` |
| 사자성어 | `js/proverbs_data.js` | `RAW_IDIOMS_DATA = [ … ]` | `aistudio/arr_fc.txt` |

## 남은 것 하나 (급하지 않음)

AI Studio 의 **Export → Push to GitHub** 를 앱마다 한 번씩 눌러 두면
소스 저장소(`claix_quiz_*`)도 AI Studio 와 같은 판으로 맞춰집니다.
지금도 내용은 같지만, 눌러 두면 «어디가 최신인지» 헷갈릴 일이 없습니다.
