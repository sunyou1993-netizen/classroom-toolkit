# AI Studio 반영 상태 (2026-09-10)

AI Studio 앱의 원본 문항을, 검증한 문항으로 바꾸는 작업입니다.

| 앱 | AI Studio 반영 | 문항 수 |
|---|---|---|
| 환경보호 | ✅ 완료 | 160 → **151** |
| 학교폭력 | ✅ 완료 | 100 → **150** |
| 안전 | ⬜ **남음** | 150 → 151 로 바꿔야 함 |
| 속담맞추기 | ⬜ **남음** | 129 → 153 |
| 사자성어 | ⬜ **남음** | 144 → 154 |

보드에 나가는 화면(`quiz/*/assets/*.js`)과 소스 저장소는 **다섯 개 모두 끝났습니다.**
여기 남은 것은 «AI Studio 화면에서도 같아지게» 하는 것뿐입니다.

## 왜 남았나

AI Studio 앱은 잠들어 있으면 화면 가운데 **Launch** 버튼이 뜹니다.
이 버튼은 **사람이 직접 눌러야만** 동작합니다 — 자동으로는 못 누릅니다
(클릭·엔터·자바스크립트 전부 시도해 봤습니다). Launch 를 안 하면
코드 편집기가 «Loading code...» 에서 멈춥니다.

## 안 하면 무슨 일이 생기나

당장은 아무 일도 없습니다. 학교에 나가는 것은 이미 다 바뀌었습니다.

문제는 **다음에 AI Studio 에서 그 앱을 고칠 때**입니다.
안전·속담·사자성어를 AI Studio 에서 한 번 손대고 다시 빌드하면,
그 세 개는 **검증 전 문항으로 통째로 되돌아갑니다.**

## 남은 세 개를 마치는 법

앱마다 이 순서입니다. (사람이 할 일은 2번 «Launch» 한 번뿐입니다)

1. aistudio.google.com → My apps → 앱 열기
2. 화면 가운데 **Launch** 를 누른다  ← 이것만 사람이
3. 위쪽 **Code** 탭을 누른다
4. 왼쪽에서 `js` → `main.js` (속담·사자성어는 `js` → `proverbs_data.js`)
5. 아래 «바꿀 자리» 를 통째로 아래 주소의 내용으로 교체
6. ⌘S 로 저장 → 왼쪽에 «Checkpoint» 가 뜨면 끝

| 앱 | 파일 | 바꿀 자리 | 넣을 내용 |
|---|---|---|---|
| 안전 | `js/main.js` | `questions: [ … ]` | [arr_safe.txt](https://raw.githubusercontent.com/sunyou1993-netizen/classroom-toolkit/main/quiz/scripts/questions/aistudio/arr_safe.txt) |
| 속담맞추기 | `js/proverbs_data.js` | `RAW_PROVERB_DATA = [ … ]` | [arr_pv.txt](https://raw.githubusercontent.com/sunyou1993-netizen/classroom-toolkit/main/quiz/scripts/questions/aistudio/arr_pv.txt) |
| 사자성어 | `js/proverbs_data.js` | `RAW_IDIOMS_DATA = [ … ]` | [arr_fc.txt](https://raw.githubusercontent.com/sunyou1993-netizen/classroom-toolkit/main/quiz/scripts/questions/aistudio/arr_fc.txt) |

3~6번은 클로드에게 시키면 됩니다. Launch 만 눌러 주시고 «눌렀어» 라고 하시면 됩니다.

## 반영이 끝난 뒤

AI Studio 의 **Export → Push to GitHub** 를 누르면 소스 저장소도 같이 맞춰집니다.
(AI Studio 는 «올리기» 만 되고 «받아오기» 는 없습니다 — 확인했습니다)
